# Distribution Fitting Test

## 개요

이 프로젝트는 `0`부터 `N`까지의 정수 범위에서 생성한 **완전히 랜덤한 데이터셋**으로부터
누적분포(CDF, Cumulative Distribution Function)를 만들고,
그 CDF를 **아주 간단한 ML 모델**로 근사할 수 있는지 테스트하기 위한 실험용 프로젝트입니다.

핵심 목적은 다음과 같습니다.

- 데이터가 학습하기 좋은 형태라는 가정을 두지 않음
- 값이 낮은 구간에 치우친 경우를 테스트
- 값이 높은 구간에 치우친 경우를 테스트
- 양 끝단에 동시에 몰린 경우를 테스트
- 평균과 분산을 조절하면서 다양한 분포적 특성을 실험
- 단순한 모델이 얼마나 안정적으로 누적분포를 근사하는지 확인

즉, 이 프로젝트는 "예쁘게 정리된 분포"가 아니라,
**불균형하고 예측하기 어려운 랜덤 데이터**에 대해
간단한 모델이 어느 정도까지 CDF를 따라갈 수 있는지를 보는 데 초점을 둡니다.

## 실험 아이디어

실험 흐름은 아래와 같습니다.

1. `0..N` 범위의 데이터를 생성
2. 생성된 데이터로 히스토그램 또는 빈도표를 계산
3. 이를 누적합하여 누적분포(CDF) 생성
4. 입력값 `x`에 대해 `CDF(x)`를 예측하는 간단한 ML 모델 학습
5. 실제 CDF와 예측 CDF를 비교

예를 들어:

- 입력: `x` 값 (`0`부터 `N`)
- 출력: 해당 지점까지의 누적확률 `CDF(x)` (`0.0` ~ `1.0`)

이 구조는 회귀(regression) 문제로 볼 수 있으며,
가벼운 실험용 모델로 다음과 같은 후보를 고려할 수 있습니다.

- `MLPRegressor`
- 작은 fully-connected neural network
- 얕은 decision tree regressor
- polynomial regression 같은 매우 단순한 baseline

초기 목표는 복잡한 모델을 쓰는 것이 아니라,
**최소한의 모델로도 랜덤 분포의 누적곡선을 어느 정도 근사할 수 있는지**를 확인하는 것입니다.

## 데이터 생성 조건

이 프로젝트에서 중요한 조건은 데이터셋이 **완전히 랜덤**이어야 한다는 점입니다.
즉, 학습이 쉬운 형태로 데이터를 인위적으로 정렬하거나 정제하지 않습니다.

다음과 같은 특성이 모두 가능해야 합니다.

- 낮은 값에 대부분 몰림
- 높은 값에 대부분 몰림
- 중간에 몰림
- 양쪽 극단에 몰림
- 비교적 평평하게 퍼짐
- 평균은 비슷하지만 분산이 크게 다른 경우
- 분산은 비슷하지만 평균이 크게 다른 경우

이를 위해 데이터 생성 단계에서 평균과 분산을 `config`로 제어할 수 있도록 설계합니다.

## Config 항목

초기 구현에서 다루면 좋은 설정값은 아래와 같습니다.

| 항목 | 설명 |
| --- | --- |
| `N` | 데이터 값의 최대 범위. 데이터는 `0`부터 `N` 사이에서 생성 |
| `sample_size` | 생성할 데이터 개수 |
| `mean` | 데이터 분포 중심을 조절하기 위한 평균 |
| `variance` | 데이터 퍼짐 정도를 조절하기 위한 분산 |
| `seed` | 재현 가능한 실험을 위한 랜덤 시드 |
| `distribution_mode` | 데이터 생성 패턴 선택용 옵션 |
| `model_type` | 사용할 단순 ML 모델 종류 |
| `train_ratio` | 학습/평가 분할 비율 |

예시:

```yaml
N: 100
sample_size: 5000
mean: 30
variance: 200
seed: 42
distribution_mode: mixed
model_type: mlp
train_ratio: 0.8
```

## 분포 생성 시나리오

완전히 랜덤한 데이터라고 해도,
실험 목적상 "어떤 랜덤성"을 줄 것인지는 몇 가지 시나리오로 나누어 테스트하는 것이 좋습니다.

예상 시나리오는 다음과 같습니다.

### 1. Low-Biased

- 평균이 낮고 분산이 작은 경우
- 값이 `0` 근처에 몰리는 케이스

### 2. High-Biased

- 평균이 높고 분산이 작은 경우
- 값이 `N` 근처에 몰리는 케이스

### 3. Wide Spread

- 분산이 큰 경우
- 전체 구간에 넓게 퍼지는 케이스

### 4. Bimodal / Edge-Focused

- 작은 값과 큰 값 양쪽에 몰리는 케이스
- 중간은 상대적으로 비는 형태

### 5. Noisy Random

- 뚜렷한 구조 없이 랜덤 샘플링된 케이스
- 모델이 일반화하기 가장 까다로운 기준선 실험

## 모델링 목표

모델의 목표는 확률밀도함수(PDF)를 직접 맞추는 것이 아니라,
보다 안정적인 형태인 **누적분포(CDF)** 를 근사하는 것입니다.

CDF를 대상으로 하는 이유:

- 값이 단조 증가하므로 학습이 상대적으로 안정적임
- 노이즈가 많은 데이터에서도 PDF보다 덜 불안정함
- 분포 전체의 형태를 비교하기 쉬움

입력과 출력은 아래처럼 정의할 수 있습니다.

- 입력 `x`: `0..N`
- 타깃 `y`: 정규화된 누적확률 `CDF(x)`

## 평가 방법

추천하는 평가지표는 다음과 같습니다.

- `MSE`: 실제 CDF와 예측 CDF의 평균제곱오차
- `MAE`: 절대오차 평균
- `R^2`: 회귀 적합도 확인
- 시각화 비교: 실제 CDF vs 예측 CDF

추가로 다음 항목도 확인하면 좋습니다.

- 예측 결과가 단조 증가 형태를 어느 정도 유지하는지
- 특정 구간에서 오차가 집중되는지
- 평균/분산 설정이 달라질 때 성능이 얼마나 흔들리는지

## 예상 프로젝트 구조

구현은 아래 정도의 단순한 구조로 시작할 수 있습니다.

```text
Distribution_Fitting_Test/
├─ README.md
├─ config.yaml
├─ main.py
├─ data_generator.py
├─ cdf_builder.py
├─ model.py
├─ evaluator.py
└─ outputs/
   ├─ plots/
   └─ metrics/
```

각 파일 역할:

- `config.yaml`: 실험 설정
- `data_generator.py`: 랜덤 데이터 생성
- `cdf_builder.py`: 히스토그램 및 누적분포 계산
- `model.py`: 간단한 ML 모델 정의 및 학습
- `evaluator.py`: 성능 측정 및 시각화
- `main.py`: 전체 파이프라인 실행

## 구현 범위 초안

1차 구현에서는 아래 수준이면 충분합니다.

1. `config`로 `N`, `sample_size`, `mean`, `variance`, `seed`를 입력받기
2. 랜덤 데이터 생성
3. 생성 데이터로 실제 CDF 계산
4. 간단한 회귀 모델 1개 학습
5. 실제 CDF와 예측 CDF를 그래프로 저장
6. 오차 지표 출력

그 다음 단계에서 확장할 수 있습니다.

- 여러 모델 비교
- 여러 분포 모드 비교
- 여러 시드 반복 실험
- 평균/분산 sweep 실험
- 단조성 보정 후처리

## 이 프로젝트에서 확인하고 싶은 질문

이 실험으로 확인하려는 핵심 질문은 다음과 같습니다.

- 매우 단순한 모델이 랜덤 분포의 CDF를 어느 정도까지 근사할 수 있는가?
- 평균과 분산이 달라질 때 성능은 어떻게 변하는가?
- 데이터가 한쪽 또는 양쪽 극단에 치우칠 때도 근사가 가능한가?
- 노이즈가 심하고 학습 친화적이지 않은 데이터에서도 일관된 결과가 나오는가?
